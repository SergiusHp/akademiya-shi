# Академія ШІ — версія 2

Відкрийте **index.html** подвійним клацанням у сучасному браузері. Встановлення, акаунти й API-ключі не потрібні. Інтернет використовується лише для шрифтів і зовнішніх джерел.

## Що всередині
- 20 модулів у трьох етапах: Основи → Робочі навички → Агенти й автоматизація.
- 74 уроки, 109 питань у тестах; поріг модуля — 75%.
- Практична вправа з чеклістом самоперевірки в кожному модулі, джерела та нотатки.
- 3 проєкти для портфоліо (дослідження, сайт, автоматизація).
- Майстерня: конструктор промпту, оцінка токенів, калькулятор витрат A/B, паспорт агента, карта доказів, 6 сценаріїв рішень.
- Бібліотека шаблонів із пошуком, категоріями й обраним, глосарій на 28 термінів.
- Прогрес, повторення помилок, резервна копія (JSON) і особиста відмітка проходження.
- Фінальний іспит: 20 випадкових питань, по одному з кожного модуля; прохідний бал 80%.

## Звідки матеріал
Курс поєднує першу версію «Академії ШІ» з програмою «ШІ-Майстер». Уроки ШІ-Майстра позначені як «Поглиблення».

## Прогрес
Зберігається лише в цьому браузері. Для перенесення на інший пристрій: «Прогрес» → «Створити копію» → скопіюйте текст і збережіть; на новому пристрої вставте й натисніть «Відновити». Не записуйте сюди паролі, ключі й токени.

## Для редагування
- `src/template.html` — розмітка, `src/styles.css` — стилі, `src/logic.js` — логіка, `src/runtime.js` — рушій шаблонів.
- `src/course.json` — зміст курсу; він генерується командою `node tools/merge-course.cjs` із `src/source/`.
- Після змін зберіть файл: `node tools/build.cjs` (потрібен Node.js).

## Дизайн (версія 3)
- Дизайн-система: токени кольору, шрифтів, відступів і радіусів у `src/styles.css`; іконки — власні контурні піктограми в `src/icons.cjs` (збираються в CSS-маски).
- Шрифти: Literata для заголовків і текстів уроків, Onest для інтерфейсу. Один акцентний колір — синій; жовтий маркер виділяє лише головну думку уроку.
- Головна: що ви навчитеся, для кого курс, як проходить навчання, програма за етапами, тренажери. Кнопка «Почати / Продовжити навчання» веде до наступного незавершеного кроку.
- Маршрути з адресою сторінки (`#/modul/05`, `#/biblioteka` тощо): працює кнопка «Назад» у браузері, сторінкою можна поділитися.
- Мобільне меню, стани завантаження, порожні стани, помилки форм, підписи для екранних читачів, підтримка «зменшеного руху».
- Без інтернету шрифти замінюються системними (Palatino/Georgia і Segoe UI).


## Облікові записи й збереження прогресу (Supabase)

За замовчуванням прогрес зберігається в браузері. Щоб люди реєструвалися за email, а прогрес зберігався на сервері й був доступний на всіх пристроях:

1. Створіть безкоштовний проєкт на [supabase.com](https://supabase.com).
2. У **SQL Editor** виконайте вміст файлу `supabase/setup.sql` (таблиця `progress` + правила доступу: кожен бачить лише свій рядок).
3. У **Authentication → Providers** переконайтеся, що Email увімкнено. У **Authentication → URL Configuration** вкажіть `Site URL` = `https://sergiushp.github.io/akademiya-shi/`.
4. У **Project Settings → API** скопіюйте `Project URL` і ключ `anon public` та впишіть у `src/config.json`:
   ```json
   { "supabaseUrl": "https://xxxx.supabase.co", "supabaseAnonKey": "eyJ..." }
   ```
5. `node tools/build.cjs`, потім закомітьте й запуште `index.html`.

Ключ `anon` публічний за задумом — захист забезпечують правила RLS. **Ніколи** не вписуйте `service_role`.
